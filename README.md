# VirtualWorks, Task 1 

## Task 1: Healthcare Data Cleaning And Understanding 

### 📌 Overview
This repository contains the implementation for **Task 1** of the VirtualWorks LAB project. The primary goal of this task is to perform data cleaning and basic analysis on a healthcare datastet.

---

## 🚀 Key Features
- **Feature 1:** Checked for duplicates - None found 
- **Feature 2:** Remove blank spaces - Using TRIM
- **Feature 3:** Removed Unnecessary columns - Added S.no column for easier tracking
- **Feature 3:** Basic analysis - Patient count, common diseases, average age 

---

## 🛠️ Tools
Only Excel - Remove Duplicates, TRIM, Flash fill, COUNT, AVERAGE, FILTER 

---

## 📁 File Structure 

- healthcare_analysis - RAW data 
- Working sheet - Cleaned data 
- Basic analysis - analysis performed
